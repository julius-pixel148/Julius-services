# Julius Services website

Chimney services and home maintenance. A static site with the same design as the Julius Remodeling Group site: shared `site.css` and `site.js`, an `assets/` folder, and pages generated by one script. No dependencies.

## 1. Add your business details

Open `site.js` and fill in the `CONFIG` block at the top. Every page reads from it:

```js
var CONFIG = {
  phone: "",
  email: "",
  license: "",
  insurance: "",
  hours: "",
  address: "",
  formEndpoint: ""
};
```

Anything left blank shows on the site as a dashed placeholder such as `[Phone]`, so you can see what is still missing. Fill in all of them before going live.

## 2. Connect the booking form

`book.html` has a request form. It works in three stages, depending on what is filled in `site.js`:

1. `formEndpoint` set: requests are sent to you. Create a free form at https://formspree.io, copy its address (`https://formspree.io/f/xxxxxxx`), and paste it in.
2. Only `email` set: the visitor's email app opens with the request ready to send.
3. Neither set: the visitor sees their request and is asked to call.

## 3. Change the wording

All page text lives in `tools/build-pages.rb`. Edit it there, then rebuild:

```sh
ruby tools/build-pages.rb .
```

Do not edit the `.html` files by hand; the next rebuild overwrites them.

When you have a web address, put it in `SITE_URL` at the top of that script and rebuild. That writes `sitemap.xml` and adds the right links for search engines.

## 4. Things to review before launch

- **Read every claim.** The copy describes how visits work (floors covered, photos, a price before repairs, a written report). Change anything that is not how you operate.
- **Services.** Remove any you do not offer from `CHIMNEY` / `HOME_CARE` and `PAGES` in the build script.
- **Reviews.** There is no reviews section yet. Add one once Julius Services has its own reviews.
- **Photos.** Your originals are in `Photos/` (not published). Web-sized copies are in `assets/photos/` and are listed in `PHOTOS` near the top of the build script. To add one, save a JPG in `assets/photos/`, add an entry to `PHOTOS`, and use its key as a page's `photo:` or in its `gallery:`.
- **Added with the photos.** An air duct cleaning page and a fireplace conversions section (wood to gas, gas to electric), because the photos show them. Remove them if you do not offer those.

## Preview

```sh
ruby -run -e httpd . -p 8124
```

Then open http://localhost:8124

## Deploy

Same as the remodeling site: push this folder to its own GitHub repo, then on https://vercel.com choose **Add New → Project → Import**. Framework preset: **Other**. Leave the build command and output directory empty.
